## Nice Try
 
A third-person 3D action-adventure game built with **Unity 6** and the **Universal Render Pipeline (URP)**, featuring melee combat, character animation, and a multi-chapter narrative structure. 3D character and environment assets were sourced from the Unity Asset Store and custom-created in **Blender**.

## 📖 Overview
 
**Arkavidia Game** is a story-driven 3D adventure where the player explores multiple chapters, engages in telekinesis combat, time bending ability, and navigates environments built with modular fantasy assets (bridges, nature packs, terrain). The game is structured around a chapter system — including a main menu, several playable chapters, and a credits scene — supporting a narrative campaign format.

## 🧰 Tech Stack
 
| Component            | Technology                                  |
|------------------------|-----------------------------------------------|
| Engine                 | Unity **6000.3.6f1** (Unity 6)               |
| Render Pipeline        | Universal Render Pipeline (URP) 17.3.0       |
| Scripting              | C#                                            |
| Camera System           | Cinemachine 3.1.5                            |
| Input Handling          | Unity Input System 1.18.0                    |
| Navigation              | AI Navigation (NavMesh) 2.0.9                |
| UI                      | Unity UGUI 2.0.0                              |
| Visual Scripting        | Unity Visual Scripting 1.9.9 (included)      |
| 3D Modeling             | Blender (source assets, exported as `.fbx`)  |
| Version Control         | Git + Unity Collaborate proxy package         |
